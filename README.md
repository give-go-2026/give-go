# Give & Go

## Installation

### Prerequisites

- **Node.js** (v24+) or **Bun** (v1.3.4+)

### Using Node.js

```bash
# Clone the repository
git clone https://github.com/hrustinszkiadam/give-n-go.git
cd give-n-go

# Install dependencies
npm install

# Start the project
npm run dev
```

### Using Bun

```bash
# Clone the repository
git clone https://github.com/hrustinszkiadam/give-n-go.git
cd give-n-go

# Install dependencies
bun install

# Start the project
bun dev
```
